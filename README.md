# MUI Documentation

Documentation for the **Multiscale Universal Interface (MUI)**.

MUI is a lightweight library for coupling heterogeneous simulation codes in multiphysics and multiscale applications. It provides a unified framework for exchanging data between independently developed solvers while supporting spatial and temporal interpolation, non-conformal mesh transfers, and advanced coupling algorithms.
